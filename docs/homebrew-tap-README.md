# getveil/homebrew-tap

Homebrew tap for [Veil](https://github.com/getveil/veil) and (future)
related tools.

## Install

```
brew install getveil/tap/veil
```

That's the only command you need. Brew auto-discovers the tap from the
`getveil/tap/<formula>` triple — no separate `brew tap` step required.

## What's here

| Formula | Description |
|---------|-------------|
| `veil`  | Protect your secrets from AI coding agents via a local credential-injecting proxy |

## How updates work

The `Formula/veil.rb` file is auto-generated by
[GoReleaser](https://goreleaser.com/) on every tagged release of
[`getveil/veil`](https://github.com/getveil/veil). Do not edit it by
hand — the next release will overwrite your changes.

To bump a formula, tag a release in the upstream repo. The
[`release` workflow](https://github.com/getveil/veil/actions/workflows/release.yml)
will update this tap automatically.

## Reporting issues

Issues with Veil itself: file at
[getveil/veil/issues](https://github.com/getveil/veil/issues).

Issues with this tap (e.g. formula install failures unrelated to Veil
itself): file an issue here.
